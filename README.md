# Proyecto Final: Maquetación Web con Interactividad JS

Este repositorio contiene el proyecto final de maquetación web, donde se combina un diseño visualmente atractivo y responsivo con funcionalidades dinámicas desarrolladas en JavaScript. Es una muestra de habilidades integrales en el desarrollo frontend.

## 🌟 Actualizaciones Recientes (Rama JavaScript)

He evolucionado el proyecto base añadiendo una capa de interactividad para mejorar la experiencia del usuario (UX):
* **Interactividad Dinámica:** Implementación de lógica en JavaScript para gestionar eventos de usuario.
* **Manipulación del DOM:** Actualización de elementos de la interfaz en tiempo real.
* **Optimización de Maquetación:** Ajustes en la estructura CSS para asegurar que los elementos dinámicos mantengan el diseño original.

## 🚀 Tecnologías Utilizadas

* **HTML5:** Marcado semántico y estructurado.
* **CSS3:** Estilos avanzados, incluyendo Flexbox y Grid para un diseño totalmente responsivo.
* **JavaScript (ES6+):** Lógica funcional para dotar de vida a la interfaz.
* **Control de Versiones:** Git con flujo de trabajo basado en ramas (Branch: `JavaScript`).

## 📂 Estructura del Proyecto

* `/js`: Contiene los scripts encargados de la lógica y la interactividad.
* `/css`: Hojas de estilo organizadas para el diseño visual.
* `/assets` o `/img`: Recursos gráficos utilizados en la maquetación.
* `index.html`: Punto de entrada principal del proyecto.
